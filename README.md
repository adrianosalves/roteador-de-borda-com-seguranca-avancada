
# Laboratório - Roteador de Borda com Segurança Avançada

Este diretório contém estudos de caso e demonstrações de segurança perimetral utilizando roteadores de borda com:

- **Filtro de conteúdo web** (bloqueio de sites maliciosos)
- **IDS (Intrusion Detection System)** para monitoramento de tráfego suspeito
- **Firewall** (regras de bloqueio e segmentação)
- **VPN** (acesso remoto seguro)
- **Redirecionamento de Portas** (port forwarding seguro)

## Objetivo
Demonstrar práticas de:
- Configuração de políticas de bloqueio de sites maliciosos
- Detecção de tráfego anômalo via IDS
- Implementação de regras de firewall
- Configuração de VPN para acesso remoto seguro
- Redirecionamento de portas com segurança
